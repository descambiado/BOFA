# BOFA labs

BOFA includes labs for learning, exploration, and local practice.

They are useful, but they are not the strongest product story in BOFA today.

## Honest positioning

Use labs when you want:

- a local practice environment
- educational scenarios
- a sandbox for scripts, flows, and runtime behavior

Do not treat labs as the main reason to evaluate BOFA if what you care about is
the current flagship workflow.

The flagship workflow is in:

- [README](../README.md)
- [docs/STATUS.md](../docs/STATUS.md)
- [docs/BUG_BOUNTY_WORKSPACES.md](../docs/BUG_BOUNTY_WORKSPACES.md)

## Labs and runtime

Labs still matter because they fit into the same operational model:

- runs
- events
- artifacts
- history

That means BOFA can keep lab activity attached to the same broader runtime
story, even if labs are not the public center of gravity right now.

## Suggested use

- use labs for training and local validation
- use workspaces and review flows for the flagship duplicate-aware workflow
- avoid presenting labs as the core value of BOFA unless they are the feature
  being discussed
